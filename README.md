# minicurso-R-jurimetria
Repositório do Minicurso Introdutório ao R para Aplicações Jurimétricas

O repositório consiste nos arquivos de dados, scripts e apresentações do Minicurso de R para Aplicações Jurimétricas, atividade de extensão na Universidade Federal Fluminense realizada nos dias 25 e 26/08/2026. Trata-se de uma introdução elementar ao R, restrita a análise exploratória de dados.
