3. O texto como dado

1. Introdução

Neste momento, vamos explorar uma temática bastante importante para as ciências humanas e sociais em geral. Se nos exemplos anteriores tomamos dados quantitativos e qualitativos de tipo clássico para realizar nossas análises, agora vamos tratar o texto como dado.

A análise automatizada de textos possui precedentes na linguística, mas hoje constitui o núcleo de muitos dos chamados grandes modelos de linguagem (Large Language Models), as “inteligências artificiais”. As redes neurais que constituem esses modelos não só realizam operações complexas de análise textual sobre um volume gigantesco de dados, como incorporam o resultado dessas análises a suas funções de transformação, aprendendo a “falar” a língua e a gerar distribuições de probabilidade para a ocorrência das palavras nas sentenças, cada vez mais próximas de um falante nativo.

Muito do que vamos ver neste momento do minicurso pode ser feito pelos LLMs, mas a vantagem de programar com o R é, uma vez mais, a controlabilidade dos parâmetros e sua interpretação estatística. Neste sentido, o que vamos exemplificar é rudimentar perto do que é possível fazer com um modelo desses, mas ainda assim são operações de natureza básica para análise exploratória de dados textuais, com princípios muito semelhantes aos utilizados para outros tipos de dados.

2. Leitura e Pré-Processamento

Utilizaremos como exemplo para mostrar as diferentes operações de análise textual a análise feita no âmbito da pesquisa sobre a Machosfera do grupo C.A.O.S.-UFF (Centro de Estudos sobre Autoritarismo, Ódio e Subjetividades). Analisaremos os comentários do youtube, obtidos através de requisição pela API, no vídeo de Pablo Marçal (1 bilionário vs. 25 pobres) no podcast “Redcast”. Não se trata de um exemplo diretamente jurimétrico, mas dada a simplicidade dos textos dos comentários podemos fazer uma boa introdução a nosso tema. O exercício proposto incluirá analisar as ementas do julgamento de 8 de janeiro, como veremos adiante.

Em toda análise textual com R, precisamos, inicialmente, “limpar” o texto de elementos que consideramos não ter valor semântico apreciável como símbolos, pontuação, números e outros caracteres especiais. Notem que todas essas decisões podem ser ponderadas de acordo com os objetivos da pesquisa. No nosso caso, queremos realmente ficar apenas com o texto dos comentários. Também colocamos todas as palavras em letra minúscula e retiramos eventuais excessos de espaço entre elas.

No script abaixo, utilizamos Tidy para selecionar a variável de interesse no dataframe extraído do youtube, depois usamos as funções gsub e tolower do R base, que modificam vetores de caracteres (strings). Notem que o argumento principal de gsub são REGEX, “regular expressions”. Vocês poderão encontrar um pequeno dicionário de regex em https://www.rexegg.com/regex-quickstart.php.

A última etapa de pré-processamento textual é a remoção das stopwords. São palavras como conjunções, preposições, artigos, que não têm especial interesse em termos de significado. Por conveniência, vamos remover as stopwords depois da tokenização. O token é nossa unidade de análise. Para este exemplo, 1 token equivale a uma palavra, mas podemos trabalhar com bigramas (duas palavras), trigramas (três) e assim por diante, a depender do nosso interesse de pesquisa.

O código abaixo realiza três operações: lê um conjunto de dados de stopwords em português advindo do pacote “stopwords”, depois faz a tokenização e separa da base de dados dos tokens as stopwords. As funções utilizadas, uma vez mais, combinam R base e no caso da unnest_tokens( ) o pacote Tidytext.

# TOKEMIZAÇÃO REMOÇÃO DE STOPWORDS

stopwordsPT<-as.data.frame(stopwords(language="pt"))
colnames(stopwordsPT)<-c("word")


#Tokemização e remoção de stopwords
comentarios01_token<-comentarios01 %>%
  unnest_tokens(word, text_original) 

comentarios01_token <- anti_join(
  comentarios01_token,
  stopwordsPT,
  by = "word"
)

Observem que tinhamos 4025 comentários para analisar e temos, já contando com a remoção das stopwords, 54.295 tokens em nossa base de dados. Cliquem no dataframe “comentarios01_token” e observem a estrutura desse conjunto: 1 coluna com a identificação numérica do comentário e 1 coluna “word” com o token = 1 palavra.

3.2 Análise de Coocorrências

A análise simples de vocabulário é insensível ao contexto. Para tentar compensar um pouco o risco de um viés analítico, faremos uma análise de coocorrências. Considerando os termos-chave que extraímos na etapa anterior, quais serão as palavras que coocorrem com eles mais frequentemente?

O pacote “quanteda” é um pacote completo de análise de dados textuais, desenvolvido para a linguística de corpus. Com ele, vamos obter alguns dados importantes: 1) uma matriz de coocorrências que mede quantas vezes dois termos aparecem juntos em dado contexto (no nosso exemplo, no contexto de 5 palavras mais próximas); 2) um grafo conhecido como rede semântica, que perimite visualizar essas coocorrências espacialmente e a intensidade das ligações entre os termos. Para manipular os dados da matriz, utilizamos também um pouco de R base.

Também é de extrema utilizada a função kwic (key-word-in-context) do pacote quanteda. Ela retorna um dataframe completo que nos dá em uma coluna x palavras antes e em outra y palavras depois do nosso termo-chave.

#CO-OCORRÊNCIA DE TERMOS-CHAVE

#leitura e tokenizaçãp no padrão do quanteda
comentarios_quanteda <- corpus(comentarios01, text_field = "text_original")

tokens_quanteda <- tokens(
  comentarios_quanteda,
  remove_punct = TRUE,
  remove_numbers = TRUE) %>%
  tokens_remove(pattern=stopwordsPT$word)

#Data-frame com as palavras chave em contexto
palavraschave<-kwic(tokens_quanteda, pattern = c("bilionário", "pobre", "mentalidade","deus", "brasil", "rico"), window = 7)

#Gerar a matriz de coocorrências para medir proximidades
fcmat <- fcm(tokens_quanteda,
  context = "window",
  window = 5,
  count = "weighted")

#garantir que o R lê os valores como vetor numérico
assoc_bilionario <- as.numeric(fcmat["bilionário", ])
